# v0.2.8 OpenClaw 测试流程（REM 反重复 / 叙事新鲜度 / doctor）

目标：在真实 VPS 上验证 v0.2.8 是否真正缓解「日报素材重复」，并确认 doctor、novelty 模式、文本去重按预期工作。

环境：Ubuntu / 腾讯云 VPS / OpenClaw（建议 2026.5.27+ 或 6.5+）/ LanceDB 插槽（memory-lancedb 或 memory-lancedb-pro）。

> 所有 `dreaming_trigger` / `dreaming_status` / `dreaming_doctor` 必须在 **VPS 上的 OpenClaw** 跑，不要在本地 Windows-Cursor 节点跑。

---

## 0. 安装前快照（用于事后对比）

```bash
openclaw --version
node --version
ls ~/.openclaw/plugins/memory-lancedb-dreaming/dist/index.js

# 保留最近 3 天日报，事后对比重复度
tail -n 60 ~/.openclaw/workspace/DREAMS.md
ls ~/.openclaw/workspace/memory/dreaming/rem/ | tail -5
```

记录：最近几天 `Possible Lasting Truths` 是否反复出现同一批旧事（音色史 / 版本升级史 / 爱兔合资 等）。

---

## 1. 安装 v0.2.8 并完整重启

```bash
bash scripts/install.sh memory-lancedb-dreaming-0.2.8.tgz
openclaw gateway stop 2>/dev/null || true
openclaw gateway run
```

确认日志：

```bash
grep "memory-lancedb-dreaming" ~/.openclaw/logs/* 2>/dev/null | tail -5
# 期望: registered ... cronHook=ready ... modelOverride=ready
# 禁止: cronHook=blocked / CONFIG BLOCKED
```

---

## 2. doctor 自检（新增）

Shell 侧：

```bash
bash ~/.openclaw/plugins/memory-lancedb-dreaming/scripts/doctor.sh
```

Agent 侧（调用工具）：

```
dreaming_doctor
```

验收：`fail=0`。重点看：
- `hooks.allowConversationAccess` = PASS
- `lancedb.resolve` = PASS（含 plugin id + dbPath）
- `deep.idleStreak` 会显示当前连续空转天数（这条直接对应你遇到的重复问题）

---

## 3. dreaming_status 确认新配置已生效

```
dreaming_status
```

验收 `effectiveConfig` 应包含：
- `remTruthDedupeWindowDays: 30`
- `remTruthSimilarityThreshold: 0.42`
- `remExcludePromoted: true`
- `deepIdleNoveltyAfterDays: 7`

---

## 4. 手动跑一轮并检查产物

```
dreaming_trigger phase=all
```

```bash
DAY=$(date +%F)
cat ~/.openclaw/workspace/memory/dreaming/rem/$DAY.md
tail -n 30 ~/.openclaw/workspace/DREAMS.md
cat ~/.openclaw/workspace/memory/.dreams/lancedb-dreaming-rem-history.json | tail -40
cat ~/.openclaw/workspace/memory/.dreams/lancedb-dreaming-deep-history.json
```

验收点：
1. **REM 历史新字段**：`rem-history.json` 当天 run 含 `lastingTruthTexts` 与 `clusterThemeNames`。
2. **去重日志**：gateway 日志出现 `REM lasting truths rotated (recentId=.., similarText=.., promoted=..)`，`similarText` 或 `promoted` > 0 即去重在工作。
3. **deep-history**：`lancedb-dreaming-deep-history.json` 出现当天 `{day, promoted}`。

---

## 5. 连续 2–3 天对比（核心验收）

让 3:00 cron 自然跑 2–3 天（或每天手动 `dreaming_trigger phase=all` 一次），然后对比：

| 检查 | 通过标准 |
|---|---|
| Possible Lasting Truths 跨天 | 不再每天出现同一批旧事；同主题改写句被去重 |
| Deep 连续 `promoted=0` 当天叙事 | DREAMS.md 不再围绕旧候选写；改为当天 Light 快照或当天无新增时不写 |
| novelty 模式触发 | 连续 ≥7 天 `promoted=0` 后，日志出现 `REM novelty mode ON (Deep idle Nd ≥ 7d)` |
| 无关内容 | 真正的新主题仍能正常出现（没有被过度去重） |

---

## 6. 回归确认（不破坏既有功能）

- 日报推送仍正常（`daily report delivered via ...` 或 `unchanged` 跳过）。
- 两条 cron 仍在：`openclaw cron list` 含 `LanceDB Memory Dreaming` 与 `Dreaming Daily Report`。
- 无 `dreaming-plugin-healthcheck` 冲突 cron。

---

## 7. 回滚预案

如出现异常（过度去重 / 日报空白）：

- 临时关掉新行为：
  ```json
  "rem": { "truthSimilarityThreshold": 1, "excludePromoted": false },
  "deep": { "idleNoveltyAfterDays": 0 }
  ```
  改完 **完整重启 gateway**。
- 或换回 0.2.6 tgz 重装。
