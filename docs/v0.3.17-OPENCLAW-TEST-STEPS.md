# memory-lancedb-dreaming v0.3.17 快速验收

## 1. 覆盖安装

```bash
openclaw plugins install ./memory-lancedb-dreaming-0.3.17.tgz
openclaw gateway restart
```

确认：

- `dreaming_status.version=0.3.17`
- `dreaming_doctor` 为 `fail=0`

## 2. 主题名前缀验证

调用 `dreaming_trigger phase=all`。新生成 REM 主题不得保留以下模型格式前缀：

```text
聚类 1：
聚类1:
聚类 2、
```

例如模型原始输出为：

```text
聚类 1：东泓业务资料 / Donghong Business Data
```

最终 REM 报告和梦境日报必须显示：

```text
东泓业务资料 / Donghong Business Data
```

数字序号 `1. 主题 / Topic` 和无前缀 `主题 / Topic` 仍应正常解析。

## 3. 回归确认

- REM 无新主题时，快照保持 `rem.themeCount=0`
- 无新主题、新素材时不追加重复叙事
- 历史报告不重写
