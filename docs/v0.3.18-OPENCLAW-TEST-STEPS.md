# memory-lancedb-dreaming v0.3.18 quick acceptance

## Install

```bash
openclaw plugins install ./memory-lancedb-dreaming-0.3.18.tgz
openclaw gateway restart
```

Confirm `dreaming_status.version=0.3.18`.

## Cron stability

1. Run `openclaw cron list` and record the IDs for:
   - `LanceDB Memory Dreaming`
   - `Dreaming Daily Report`
2. Wait at least two reconcile intervals (about two minutes).
3. Run `openclaw cron list` again.

Expected:

- exactly one job exists for each name;
- both IDs are unchanged;
- the daily-report job keeps its run history and last-run state;
- no repeated add/remove activity appears in Gateway logs.

## Functional smoke

- Run each managed cron once and confirm the corresponding pipeline/report completes.
- Run `dreaming_doctor` and confirm there are no blocking findings.
