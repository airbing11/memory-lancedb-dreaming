# memory-lancedb-dreaming v0.3.15 反重复验收

> 本轮重点验证“同主题、同素材换说法”是否被拦截。

## 1. 覆盖安装

```bash
openclaw plugins install ./memory-lancedb-dreaming-0.3.15.tgz
openclaw gateway restart
```

确认 `dreaming_status.version=0.3.15`，`dreaming_doctor` 无 fail。

## 2. 第一次运行

调用 `dreaming_trigger phase=all`。如果这是升级后的首次运行，允许写入一次叙事，用于建立：

```text
memory/.dreams/lancedb-dreaming-narrative-history.json
```

同时确认 REM 历史文件仍正常更新：

```text
memory/.dreams/lancedb-dreaming-rem-history.json
```

## 3. 立即进行第二次同素材运行

再次调用 `dreaming_trigger phase=all`，预期日志包含以下至少一项：

```text
REM suppressed ... recently surfaced theme(s)
narrative filtered ... recently used source snippet(s)
snapshot narrative skipped (... novel snippet(s) < 2)
generated narrative skipped as a reworded recent entry
```

预期结果：

- 第二次 REM 报告不再输出刚出现过的相似 `Theme:` 行
- 第二次无足够新素材时不追加 `DREAMS.md` 长叙事
- 日报「关键发现」不重复刚出现的主题
- 日报「梦境叙事」显示暂无叙事，而不是换一种说法复述

## 4. 推送去重

若配置 `dailyReport.delivery.pushOn: changed`：

- 仅候选数量、置信度或散文措辞改变时，不应再次推送
- 出现真正的新主题或新的 Deep 提升时，应允许推送

## 5. 默认参数

```json
{
  "rem": {
    "themeCooldownDays": 7,
    "themeSimilarityThreshold": 0.55
  },
  "narrative": {
    "sourceCooldownDays": 7,
    "sourceSimilarityThreshold": 0.42,
    "minNovelSnippets": 2,
    "outputDedupeWindowDays": 14,
    "outputSimilarityThreshold": 0.55
  }
}
```
