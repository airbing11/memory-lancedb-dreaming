# memory-lancedb-dreaming v0.3.13 验收步骤

> ClawHub Validation 修复版：`channel-outbound` + 移除顶层 `uiHints`。

## 1. 覆盖安装

```bash
openclaw plugins install ./memory-lancedb-dreaming-0.3.13.tgz
# 或
openclaw plugins install clawhub:memory-lancedb-dreaming@0.3.13
openclaw gateway restart
```

确认 `dreaming_status.version=0.3.13`，`dreaming_doctor` 无 fail。

## 2. ClawHub / 本地校验（发布前已跑）

```bash
clawhub package validate . --openclaw-version 2026.7.2-beta.7
# 期望: Plugin Inspector PASS, Breakages 0, Warnings 0
```

## 3. 日报推送冒烟（若配置了 dailyReport.delivery）

手动触发日报 cron 或相关路径后，日志应出现：

```text
memory-lancedb-dreaming: daily report delivered via <channel> to <to>
```

不应再出现 `Cannot find module ... channel-message-runtime`。

## 4. Cron 策略回归（继承 0.3.12）

主 Dreaming 与 Daily Report 托管任务仍为：

```json
{
  "sessionTarget": "isolated",
  "payload": { "kind": "agentTurn" },
  "delivery": { "mode": "none" }
}
```

手动跑主 cron 后：`lastRunStatus=ok`，不应再报多通道 Channel required。
