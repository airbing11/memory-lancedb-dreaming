# v0.2.8 明早 5 分钟验收（cron 跑完后）

> 适用：已安装 **修正版** `memory-lancedb-dreaming-0.2.8.tgz`，等 **3:00** `LanceDB Memory Dreaming` cron 自然跑完后的第一天日报。

在 VPS 上执行（路径按你的 workspace 调整）：

```bash
export WS="${WS:-$HOME/.openclaw/workspace}"
export DAY=$(TZ=Asia/Shanghai date +%F)
```

---

## 1. cron 是否真跑了（30 秒）

```bash
grep "memory-lancedb-dreaming" ~/.openclaw/logs/* 2>/dev/null | tail -15
```

| 期望 | 说明 |
|------|------|
| `dreaming trigger received` | 3:00 左右有这条 |
| `dreaming phases completed` | light/rem/promoted/narrative 有数字 |
| `REM lasting truths rotated` | 含 `promoted=` / `recentId=`（去重在工作） |
| 无 `cronHook=blocked` | 若出现需查 hooks |

---

## 2. 当天 REM 报告（1 分钟）

```bash
cat "$WS/memory/dreaming/rem/$DAY.md"
```

| 检查项 | 通过标准 |
|--------|----------|
| Possible Lasting Truths | **不出现** 6/21–6/22 那批陈年旧事（音色史、4月升级血泪史、爱兔合资等） |
| 饱和时空列表 | `No strong candidate truths surfaced.` **可接受**（promoted 已排光时正常） |
| Reflections / Theme | **禁止** 出现 `中文主题名（4-8字） / English Topic Name`；应为真实主题名或 `` `category` `` 标签 |

---

## 3. 叙事与日报（1 分钟）

```bash
tail -n 25 "$WS/DREAMS.md"
grep -A30 "## 梦境日报" "$WS/memory/$DAY.md" 2>/dev/null | head -35
```

| 检查项 | 通过标准 |
|--------|----------|
| DREAMS.md | `promoted=0` 时不应再围着旧候选写长文；可为当天 Light 快照或当天无新增则少写/不写 |
| 梦境日报区块 | 有 `## 梦境日报`；内容与 REM 一致、无旧事回炉 |

---

## 4. 状态文件（1 分钟）

```bash
cat "$WS/memory/.dreams/lancedb-dreaming-deep-history.json"
cat "$WS/memory/.dreams/lancedb-dreaming-rem-history.json" | tail -25
```

| 检查项 | 通过标准 |
|--------|----------|
| deep-history | 含 `"day": "$DAY"` 与 `"promoted": N` |
| rem-history | 当天 run 有 `lastingTruthTexts` / `clusterThemeNames`（可为 `[]`） |

---

## 5. 推送（可选，30 秒）

```bash
grep "daily report" ~/.openclaw/logs/* 2>/dev/null | tail -5
```

| 期望 | 说明 |
|------|------|
| `delivered via` 或 `unchanged, skipping push` | 推送链路正常；内容未变则跳过也 OK |
