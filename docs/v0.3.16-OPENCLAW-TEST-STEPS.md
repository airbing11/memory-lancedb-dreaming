# memory-lancedb-dreaming v0.3.16 快速验收

## 1. 覆盖安装

```bash
openclaw plugins install ./memory-lancedb-dreaming-0.3.16.tgz
openclaw gateway restart
```

确认：

- `dreaming_status.version=0.3.16`
- `dreaming_doctor` 为 `fail=0`

## 2. 运行一次完整梦境

调用 `dreaming_trigger phase=all`。

当 `remBodyLines` 包含：

```text
No novel REM themes surfaced; recent themes are cooling down.
```

必须同时满足：

- 快照 `rem.themeCount=0`
- 日报概要显示 `🌓 REM 阶段：0 个主题模式`
- 「关键发现」显示近期主题正在冷却
- 没有新主题和新素材时不追加重复叙事

`remCount` 是参与分析的记忆数量；即使它为 200，也不得被换算为 1 个主题。
