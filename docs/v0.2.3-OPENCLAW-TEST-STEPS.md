# memory-lancedb-dreaming v0.2.3 — OpenClaw 验收步骤

> 针对 v0.2.2 推送失败（`runtime.channel.outbound.loadAdapter` 不可用）的修复版。

## 变更摘要

- 日报推送改用 OpenClaw 官方 `sendDurableMessageBatch`（与 cron announce 相同路径），不再依赖 `api.runtime.channel.outbound`。
- 推送失败时 **必定** 写 `warn`/`error` 日志（不再静默）。
- 版本 **0.2.3**；cron 仍保持 `main` + `systemEvent`、**无** `cron.delivery`。

## 安装

```bash
bash scripts/install.sh memory-lancedb-dreaming-0.2.3.tgz
# 完整重启 gateway
```

## 测前清理

1. `openclaw cron list` — 删除手建的梦境/日报 cron，保留插件托管两条即可。
2. 确认 `hooks.allowConversationAccess: true`、`subagent.allowModelOverride: true`。
3. `dreaming_status` 中 `dailyReport.delivery` 含 `channel` + `to`（如 feishu）。

## 关键验收

| # | 检查项 | 期望 |
|---|--------|------|
| C2 | Dreaming Daily Report cron | 存在，0 4 * * * |
| C5 | 两条 cron 无 delivery 字段 | ✅ |
| P3 | 跑 Dreaming cron 后日志 | `daily report delivered via feishu` |
| P4 | 飞书 | 收到梦境日报正文 |
| R3/R4 | 跑 Daily Report cron | 同上 |

失败时日志应出现例如：

`daily report delivery failed (feishu): <原因>`

## 判定

- **GO**：P3+P4 或 R3+R4 通过，且日志有 delivered 或明确失败原因。
- **NO-GO**：仍无飞书且无 delivered 日志 → 把完整插件日志片段反馈开发。
