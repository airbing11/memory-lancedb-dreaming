# memory-lancedb-dreaming v0.3.12 小泡验收步骤

> 本轮只验证 cron 完成投递修复，不发布 GitHub/ClawHub。

## 1. 覆盖安装

```bash
openclaw plugins install ./memory-lancedb-dreaming-0.3.12.tgz
openclaw gateway restart
```

确认 `dreaming_status.version=0.3.12`，`dreaming_doctor` 无 fail。

## 2. Cron 配置

主 Dreaming 和 Daily Report 两条托管任务都必须是：

```json
{
  "sessionTarget": "isolated",
  "payload": { "kind": "agentTurn" },
  "delivery": { "mode": "none" }
}
```

升级后的 reconcile 应原地更新现有任务，不应产生重复 cron。

## 3. 主 Dreaming 验收

手动运行托管的 `LanceDB Memory Dreaming` cron，等待结束后确认：

- Light / REM / Deep / Narrative 正常
- `lastRunStatus=ok`
- `lastDeliveryStatus=not-requested`（或等价的未请求投递状态）
- 不再出现 `Channel is required when multiple channels are configured`

## 4. 日报验收

手动运行托管的 `Dreaming Daily Report` cron，确认：

- `lastRunAt` 更新且 `lastRunStatus=ok`
- `delivery.mode=none` 没有产生额外 cron announce
- 当日报内容有变化时，插件自己的飞书私聊仍成功送达
- `pushOn=changed` 且内容无变化时，不重复推送

## 5. 回传

请回传两条 cron 的：

- `sessionTarget`
- `payload.kind`
- `delivery.mode`
- `lastRunAt`
- `lastRunStatus`
- `lastDeliveryStatus`
- 对应 Gateway warning/error
